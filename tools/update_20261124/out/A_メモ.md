## 判断
- 「後日登場予定」は無視し注記なし。
- 形式は既存recから逆算。同じ処理で既存の ネコヤン G1/G2、バチ G1、タロー G2、神秘の館 G11 を再現して一致を確認(差は下記の c・m のみ)。
- 1recは1アイテム(複数アイテム併記の表は分割)。
- オプション名の空白を除去(例「Str + 7」→「Str+7」、「スキルディレイ - 15%」→「スキルディレイ-15%」)。既存ids/descのキー形式に合わせるため。
- 精錬条件 c: 表の条件をスロットごとに展開(ネコヤンは6/8/10、神秘の館は「精錬値8以上」)。「精錬不要」は文字列「精錬不要」(バチ・ミオン・ソラマメと同じ。既存タロー G2 は空文字)。超越段階「0以上」は req=[](既存と同じ)。
- grp 表記は NPC ごとの既存に合わせた: タロー=「NPCタロー グループN」、ネコヤン=「グループN」、ヤマカケ(新規NPC)=「ヤマカケ グループN」(バチ・ミオン方式)。
- brk: 失敗時「対象アイテムが消滅」=あり(ヤマカケ G1のみ)、「ー」「-」=なし。
- note: ネコヤンは既存が空文字のため空文字。ヤマカケ・タロー G3 は ページの「その他」から作成(バチの文言に準拠)。タロー G2 は既存 G2 と同文。
- クロノアルケミア[0] のスロット行は「カードスロットが必ず付与される(選択不可)」として o=["カードスロット追加"]、m=スロット追加、n に説明。既存の「選択」型スロットとは別扱い(既存形式に「必ず付与」の前例なし)。
- ヤマカケ G2 の note に「第2〜4スロットにエンチャントが施されている場合のみ選択可」を追記。
- 神秘の館: 効果欄の「※異境の統轄者はセット効果のみ発動…」は o から除き、既存G11と同じく note と step.n に「異境の統轄者はセット効果のみ発動」。
- ファロス: 既存ベテランrecと同じ place・cost、m=ランダム、c=空。エリート遺物細工師側の変更なし。
- 暴食の宝玉 ID 1002026 は EnchantDB/rotool/all_names.json の名称一致。禁断の構築 315738 は rotool 検索キャッシュの名称一致。XVの2件は all_names の名称一致。
